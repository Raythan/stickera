# Internationalization (i18n)

> **SDD:** spec i18n. Validação: [SPEC-VALIDATION.md](SPEC-VALIDATION.md) §2. Processo: [SDD-DEVELOPMENT.md](SDD-DEVELOPMENT.md).

Default locale: **English (`en`)**. Structure must allow adding locales without code changes.

## Libraries

- `i18next`
- `react-i18next`
- `expo-localization` — device default on first launch

## File layout

```
src/i18n/
  index.ts              # init i18next
  resources.ts          # import JSON locales
  locales/
    en.json
    pt.json
  keys.ts               # optional: keyof helper for typed keys (later)
```

## Key naming convention

```
screens.home.title
screens.pack.openButton
albums.spaceExplorers.name
albums.spaceExplorers.stickers.01.name
trade.confirm.title
about.tagline
errors.pack.notReady
```

- **camelCase** segments after namespace
- Album content uses `nameKey` from manifest → same key in all locale files

## Example `en.json`

```json
{
  "screens": {
    "home": { "title": "My Albums" },
    "pack": { "openButton": "Open pack", "cooldown": "Next pack in {{time}}" }
  },
  "albums": {
    "spaceExplorers": {
      "name": "Space Explorers",
      "stickers": { "01": { "name": "Nebula Cat" } }
    }
  }
}
```

## Usage in components

| Layer | Rule |
|-------|------|
| Atoms | Receive translated `string` props |
| Molecules+ | `const { t } = useTranslation()` |
| Domain | Never import i18n; use keys only in UI |

Interpolation:

```tsx
t('screens.pack.cooldown', { time: formattedDuration })
```

Pluralization (duplicates):

```json
"collection": {
  "duplicateCount_one": "{{count}} duplicate",
  "duplicateCount_other": "{{count}} duplicates"
}
```

## Adding a locale

1. Copy `en.json` → `{locale}.json`.
2. Register in `resources.ts`.
3. Add language name to Settings picker via `languages.{code}` keys.
4. No component edits if keys unchanged.

## Settings

- User override stored in SQLite `settings.locale`.
- Fallback chain: user → device → `en`.

## Content vs UI strings

| Source | Example |
|--------|---------|
| UI chrome | `screens.*`, `trade.*` |
| Album copy | `albums.*` from manifest `nameKey` |
| Config tagline | `about.tagline` via `signature.taglineKey` |
